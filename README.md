# Product Inventory Tracker

A web application built using ASP.NET Core MVC and C# to manage product inventory.

## Features
- Add new products
- View product details
- Edit products
- Delete products
- Product dashboard
- SQL Server database integration

## Technologies Used
- C#
- ASP.NET Core MVC
- Entity Framework Core
- SQL Server
- HTML
- CSS
- Bootstrap

## Project Purpose
This project was created to practice MVC architecture, CRUD operations, database connectivity, and web development using .NET.
